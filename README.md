# Smart Waste Management App

A full Expo Router mobile app scaffold inspired by the design you shared.

## Features included
- Login / register screen
- Home dashboard
- Waste report screen
- AI waste detection mock
- Collection schedule
- Pickup request
- Recycling guide
- Rewards and profile
- Firebase-ready auth/report saving service

## Run
1. Install dependencies:
   npm install
2. Copy `.env.example` to `.env` and add Firebase keys if you want auth/database.
3. Start the app:
   npx expo start

## Notes
- AI detection is mocked for now.

- If Firebase is not configured, the app still works in demo mode.
